# 既知の問題

公開版（コミット `962bfca`）の時点の問題です。原因が rvt-rs 側にあるものは「rvt-rs」と書いています。数値は [確認に使ったファイル](README.md#確認に使ったファイル) での実測値です。

## 読み込み

### Revit 2027 のファイルを開くと「メモリが不足しました」と表示される

- 現象: 2027 版の `racbasicsampleproject.rvt`（19 MB）を開くと「メモリが不足しました。ファイルが大きすぎる可能性があります。」と表示され、ファイル情報も表示されない。
- 原因 1（rvt-rs）: 要素の読み取り中に `vendor/rvt-rs/src/walker.rs:688` でパニックする。UTF-16 文字列の長さ（`u32` の文字数 × 2）に 4 を足す計算が、`usize` が 32 bit の WebAssembly では桁あふれし、長さの確認をすり抜けて範囲外のスライスを取る。64 bit のネイティブ実行ではパニックせず、要素 0 件として開ける（2027 の要素は rvt-rs が未対応）。
- 原因 2（本アプリ）: wasm のパニックは `RuntimeError: unreachable` として届き、読込エラーの分類（`src/app/document.ts` の `classifyError`）が `unreachable` をメモリ不足と判定している。
- 回避策: なし。

### Revit 2022 以前のファイルは要素を表示できない（rvt-rs）

ファイル情報（メタデータ）のみです。rvt-rs が 2022 以前の要素レコードを読めないためです。

### ホーム画面の「対応状況」に Revit 2026 が載っていない

2026 は 2024 / 2025 と同じように表示できることを確認済みですが、ホーム画面の表示は「その他のバージョン: ファイル情報のみ」のままです。

## 形状

### 壁の開口が切り欠かれない、一部の形状が箱になる（rvt-rs）

rvt-rs が形状を復元しないもの: 壁の開口（ドア・窓の箱を壁の厚みに切ったものになる）、寄棟・切妻屋根、一部の階段（モノリシック、蹴込みなし、らせん）、編集した壁プロファイル。

### 保存済み表示メッシュで置き換えられない要素が残る

rvt-rs が箱で出力した要素は、Revit がファイルに保存した表示用メッシュで置き換えています。置き換えられずに箱のまま残る主な原因と件数は次のとおりです（公開版。原因は 1 要素に複数ある場合があります）。

| 原因 | 主な要素 | 件数 |
| --- | --- | ---: |
| 円錐面（`ConeSurf`）を rvt-rs が三角形化できない | 配管継手 | rmebasic 162 |
| 線織面の輪郭曲線が null（一端が点）で rvt-rs が読めない（`missing surface pointer target`） | ダクト継手 | rmebasic 105 |
| 円柱面のトリムが長方形でない（`nonrectangular cylinder trim`） | 配管継手、家具、手摺 | rmebasic 58、racadvanced 17、racbasic 7 |
| 円柱面のトリムが複数ループ | 配管継手 | rmebasic 46 |
| 円柱面の座標系が左手系（`left-handed cylinder basis`） | 家具、基礎、一般モデル、柱 | racbasic 14、rmebasic 7、racadvanced 1 |
| ルートのインスタンスに `m_forbiddenTarget` がある（`instance target restrictions are unsupported`） | 家具 | racadvanced 60 |
| 手摺の反転コントロール `GBiFlipControl` を rvt-rs の走査が拒否する | 手摺 | racadvanced 9 |
| 楕円・エルミート スプラインの輪郭、曲がった線織面 | 家具、梁、一般モデル | 数件 |
| 保存済みグラフィックスに閉じた面がない | 階段、カーテンウォール | 各サンプル数件 |

- rvt-rs は 1 つの面の三角形化に失敗すると、その面を含む形状（`Geometry`）全体を捨てます。曲面に接する平面も、隣の曲面を参照して失敗するため巻き添えになります。
- 同じ ElementId を複数のエンティティが持つ要素（分割して出力される床など）は、どの部分のメッシュか決められないため対象外です。
- 曲面の三角形化と、走査の制限の緩和は対応作業中です（未公開）。

### RPC（樹木・人物・車）は代替形状で表示される

- 樹木・人物はシルエット、車は簡易な立体で表示されます。Revit の非レンダリング表示と同じ代替形状です。写真のような見た目（ArchVision の RPC コンテンツ本体）はファイルに含まれていないため表示できません。
- カテゴリは「一般モデル」と表示されます（Revit では植栽・添景）。rvt-rs が `IfcBuildingElementProxy` として出力し、Revit のカテゴリを渡さないためです。

### ガラスなど透明なマテリアルが不透明に表示される

保存済み表示メッシュで描いた要素は、要素ごとに 1 色で描いています。窓のガラスと枠が同じ色・不透明になります。Revit は面ごとのマテリアル（不透明度を含む）を保存していますが、まだ使っていません。対応作業中です（未公開）。

## 性能

- 保存済み表示メッシュの読み込みは、要素の解析の後に裏で行います。ネイティブ実行で Core Interior 2.4 秒、racadvanced 13.7 秒、rmebasic 9.6 秒かかり、ブラウザ（WebAssembly）ではこの 2 〜 3 倍かかります。重い場合は「ファイル → オプション」で無効にできます（次に開くファイルから反映）。
- WebAssembly のメモリは 4 GiB が上限で、一度確保すると解放されません。ファイルを開くたびに Worker を作り直して解放しています。

## その他

- 保存済み表示メッシュの読み込み中に wasm がパニックした場合、同じインスタンスでの以降の処理（書き出しなど）の安全性は保証されません。メッシュは箱のままとなり、トーストで通知します。
- パラメータは一部のみ読み取れます（rvt-rs）。
- 動作確認は Chromium 系ブラウザのみです。
